# 桑榆智援 · 社区独居老人诉求智能体（演示版）

面向社区独居老人的诉求上报与研判智能体。老人对着手机说一句方言，系统把它变成一张社区能直接派工的标准工单。

> 郑州大学首届 AI 智能体创新应用大赛参赛作品 · 全部数据为模拟脱敏数据，不含真实居民信息。

## 在线演示

打开 **[index.html](index.html)** 即为登录页，选身份后进入：

| 端 | 页面 | 演示账号 |
|---|---|---|
| 老人端 | `elder.html` | 编号 `E1001` · 密码 `123456`（王秀兰） |
| 社区端 | `admin.html` | 用户 `sg001` · 密码 `sq123456`（网格员张桂芳） |

在线版可完整体验：语音/打字上报、工单自动成单、社区端接单处置、进度回显、档案、研判预警、数据分析。
**线上版不含**两样东西（需要本机服务，见下）：

- 讯飞方言语音识别（需要本地中继服务，内含密钥）
- 两台电脑实时共享（需要局域网同步服务）

没有这两项时，语音输入自动退回浏览器识别/打字，数据退回浏览器本地存储，页面功能不受影响。

## 技术结构

```
浏览器（老人端 / 社区端）
   ├─ 语音：讯飞开放平台 · 中原官话（经本地中继，密钥只在服务端）
   ├─ 研判：Dify 工作流「桑榆智援 · 诉求研判」→ DeepSeek
   └─ 存储：浏览器 localStorage（可选局域网共享服务）
```

研判工作流定义见 [`docs/桑榆智援-诉求研判工作流.yml`](docs/桑榆智援-诉求研判工作流.yml)，可直接导入 Dify。
工作流里 DeepSeek 的 API Key 为占位符，需自行填写。

## 本地运行

```bash
python -m http.server 8123
# 浏览器打开 http://localhost:8123/index.html
```

若要接真实研判：社区端 → 设置 → 填入 Dify 服务地址（如 `http://localhost:8080`）与应用 API Key。
未填时自动使用本地规则研判，流程照常走通。
